# Тестирование

```bash
npm test            # модульные тесты ядра (Vitest)
npm run test:e2e    # браузерные сценарии (Playwright, Chromium; сам соберёт и запустит preview)
npm run typecheck   # TypeScript, strict
npm run lint        # ESLint
npm run build       # production-сборка
```

### Ожидаемое поведение в ключевых сценариях

* Куб a, середины AA₁, BB₁, CC₁ → квадрат, S = a².
* Куб, A₁BD → правильный треугольник со стороной a√2.
* Куб, AA₁C₁C → прямоугольник a × a√2, две стороны — рёбра.
* Куб, середины AB, CC₁, A₁D₁ → правильный шестиугольник со стороной a/√2.
* Тетраэдр, середины DA, DB, DC → треугольник площадью ¼ основания.
* Тетраэдр, M — сер. AD, BN : ND = 3 : 1, K — сер. BC → четырёхугольник, четвёртая вершина
  делит AC в отношении 1 : 3 (по теореме Менелая).
* Пирамида SABCD, S и середины AB, CD → треугольник площадью a·h/2.
* Касание по ребру → отрезок; по вершине → точка; совпадение с гранью → грань; плоскость
  вне фигуры → пусто.

## Независимая проверка результата

Каждое построение в приложении (и в тестах) проходит `validateSection`: принадлежность
плоскости, нахождение внутри тела, лежание сторон в гранях, замкнутость, выпуклость,
отсутствие самопересечений и сравнение с **альтернативным алгоритмом** (пересечения всех
рёбер напрямую + выпуклая оболочка в плоскости). Школьное решение проходит
`verifyConstruction`: каждое утверждение каждого шага («X ∈ α», «X ∈ (ABB₁A₁)», «MN ∥ AB»,
«прямые не параллельны», «X на ребре») перепроверяется численно.

## Браузерные тесты (`tests/e2e/app.spec.ts`)

Chromium в headless-режиме, WebGL через SwiftShader, окно 1600×950. Сценарии:

1. главная страница открывается без ошибок консоли;
2–3. выбор куба, холст действительно отрисован (анализ пикселей), подписи вершин на месте;
4. вращение мышью, масштаб колесом, вид «Сверху» (по положению камеры);
5–8. выбор трёх середин рёбер щелчками по модели (по экранным координатам рёбер) → правильный
   шестиугольник площадью 20.7846, школьное решение, переключение шагов меняет подсветку
   на сцене, на последнем шаге видно сечение;
9. удаление точки и выбор новой;
10. точка через отношение отрезков; перемещение точки ползунком пересчитывает сечение;
11. ошибки ввода: не ребро, коллинеарные точки, лишняя точка;
12. перебор всех типов фигур, смена числа сторон, пример из меню, случайная задача;
13. раскладка панелей на 1600×950, 1920×1080, 1366×768, нет горизонтальной прокрутки;
14. обучение: урок, тест с неверным и верным ответом, демонстрация, упражнение с отметкой
    вершин и объяснением ошибки;

плюс «сначала сам», «скрыть решение», самопроверка с отметкой 5 вершин, сохранение в URL и
восстановление после перезагрузки, экспорт PNG, справка.

Во всех сценариях консоль проверяется на ошибки JavaScript (сетевые ошибки загрузки
шрифтов в изолированной среде без интернета исключены из проверки).
