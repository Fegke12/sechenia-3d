# Математика «Сечения 3D»

Все вычисления — в `src/core`, в школьной системе координат: ось `z` направлена вверх,
основания призм и пирамид лежат в плоскости `z = 0`. Числа — IEEE-754 double.

## 1. Обозначения

* `L` — характерный размер многогранника: длина диагонали ограничивающего параллелепипеда.
* `ε_d = 1e-9·L` — допуск расстояния до плоскости; `ε_m = 1e-8·L` — допуск слияния точек.
* `ε_t = 1e-9` — допуск параметра на ребре.
* Для векторов: `u·v` — скалярное, `u×v` — векторное произведение.

## 2. Плоскость по трём точкам

`n = (P₂ − P₁) × (P₃ − P₁)`.

* Совпадение: `|Pᵢ − Pⱼ| ≤ ε_m` ⇒ ошибка «точки совпадают».
* Коллинеарность: `sin φ = |n| / (|P₂−P₁|·|P₃−P₁|)`, где φ — угол между векторами.
  `sin φ < 1e-6` ⇒ ошибка «точки лежат на одной прямой»;
  `sin φ < 1e-3` ⇒ плоскость строится, но выдаётся предупреждение о плохой обусловленности.
* Нормализованное уравнение: `n̂ = n/|n|`, `d = −n̂·P₁`, `f(X) = n̂·X + d` — знаковое расстояние.
* Для вывода пользователю коэффициенты дополнительно масштабируются к «красивому» виду
  (делятся на наибольший модуль), это не влияет на вычисления.

## 3. Классификация вершин

`sᵢ = f(Vᵢ)`; `σᵢ = 0`, если `|sᵢ| ≤ ε_d`, иначе `σᵢ = sign(sᵢ)`.
Классы вычисляются один раз и используются всеми последующими шагами — это гарантирует,
что соседние грани «согласны» друг с другом относительно каждой вершины и ребра.

**Согласование с допуском слияния.** Для ребра AB со строгим пересечением, если
`t·|AB| ≤ ε_m` (точка пересечения ближе ε_m к A), полагаем `σ_A = 0` (аналогично для B);
повторяем до стабилизации. Тогда никакая точка пересечения не лежит ближе ε_m к вершине, и
ложных коротких сторон не возникает. Для «привязанной» вершины `|f(A)| ≤ t·|f(A) − f(B)| ≤ t·|AB| ≤ ε_m`,
поэтому все вершины сечения удовлетворяют `|f| ≤ ε_m`.

## 4. Пересечение ребра AB

* `σ_A·σ_B < 0` — строгое пересечение: `t = s_A/(s_A − s_B) ∈ (0,1)`, `P = A + t(B−A)`.
* `σ_A = 0` (или `σ_B = 0`) — точкой пересечения служит сама вершина (без дубликатов).
* `σ_A = σ_B = 0` — ребро целиком лежит в плоскости.
* иначе — пересечения нет.

## 5. Касание (нет вершин по обе стороны)

Если не существует пары вершин с `σ = +1` и `σ = −1`, то многогранник лежит в одном
замкнутом полупространстве, и `α ∩ P = conv(Z)`, где `Z` — вершины с `σ = 0`
(для выпуклого многогранника это грань, ребро или вершина):

| `|Z|` / ранг | результат |
|---|---|
| 0 | пусто |
| 1 | точка (касание в вершине) |
| ≥ 2, коллинеарны | отрезок (плоскость содержит ребро) |
| ≥ 3, не коллинеарны | многоугольник, совпадающий с гранью |

## 6. Собственное сечение

**Лемма.** Пусть выпуклый многогранник имеет вершины по обе стороны α. Тогда α ∩ P —
выпуклый многоугольник, каждая его сторона лежит ровно в одной грани (если ребро
многогранника лежит в α, оно — сторона, общая для двух граней, и учитывается один раз),
каждая вершина — нулевая вершина многогранника или точка строгого пересечения ребра.

**Алгоритм по граням.** Для грани `(v₀ … v_{k−1})` обходим цикл и выписываем по порядку:
нулевые вершины `vᵢ` и строгие пересечения рёбер `(vᵢ, vᵢ₊₁)`. Грань, не лежащая в α,
пересекается с α по отрезку прямой, поэтому получаем 0, 1 или 2 различные точки; при 2
точках добавляется сторона сечения (с пометкой грани). Если из-за допусков точек больше
двух, они упорядочиваются вдоль прямой пересечения и соединяются последовательно.

**Сборка.** Точки сливаются по ключу происхождения (`vertex:i`, `edge:a-b`), отрезки — по
неупорядоченной паре концов. В графе каждая вершина должна иметь степень 2 (иначе —
ошибка алгоритма, результат не показывается как достоверный). Обход даёт цикл; если
ориентированная площадь (по Ньюэллу) отрицательна относительно n̂ — цикл разворачивается.

Нулевая вершина в собственном сечении всегда имеет степень 2: если бы все её соседи лежали
по одну сторону, многогранник содержался бы в конусе рёбер этой вершины, т.е. целиком в
одном полупространстве — противоречие.

## 7. Независимая проверка

1. `|f(X)| ≤ ε_d` для всех вершин и середин сторон сечения.
2. Каждая вершина внутри или на границе: `n_F·X − o_F ≤ ε_d` для всех граней.
3. Каждая сторона лежит в плоскости своей грани (оба конца и середина).
4. Многоугольник замкнут, без повторов, строго выпуклый (знаки поворотов совпадают),
   без самопересечений (попарная проверка несмежных сторон).
5. **Альтернативный алгоритм:** все строгие пересечения рёбер и нулевые вершины
   вычисляются напрямую (без топологии граней), строится выпуклая оболочка в 2D-базисе
   плоскости (монотонная цепочка Эндрю); множества вершин должны совпасть, площади —
   совпасть с точностью `1e-9·L²`.
6. Заданные точки должны лежать на границе сечения.

## 8. Точки на рёбрах и гранях

* Ребро: `M = A + t(B − A)`, `0 ≤ t ≤ 1`. Отношение `AM : MB = p : q` ⇒ `t = p/(p+q)`.
  Отношение всегда читается от первой вершины записи ребра: для `M ∈ BA` с `BM:MA = 1:2`
  `t` отсчитывается от `B`.
* Грань: `M = Σ wᵢ·Vᵢ`, `wᵢ ≥ 0`, `Σwᵢ = 1` по вершинам грани. При выборе мышью грань
  разбивается веером на треугольники, для треугольника с точкой считаются барицентрические
  координаты.

## 9. Школьное построение

Обозначим α — секущую плоскость, (F) — плоскость грани F.

* **Аксиома.** Если две точки прямой лежат в плоскости, то вся прямая лежит в этой
  плоскости. Две точки α, лежащие в (F), задают след `α ∩ (F)`.
* **Пересечение прямых в плоскости.** След ℓ в (F) и прямая ребра e ⊂ (F), не параллельные,
  пересекаются в точке X ∈ α. Если X на отрезке e — вершина сечения; иначе X — точка на
  продолжении ребра, принадлежащая плоскости второй грани ребра.
* **Параллельные плоскости.** Если (F) ∥ (G), то `α ∩ (G) ∥ α ∩ (F)`. Применяется, только
  если параллельность граней — доказанное свойство фигуры (основания призмы, противоположные
  грани параллелепипеда, противолежащие боковые грани правильной 2k-угольной призмы,
  противолежащие грани центрально-симметричных платоновых тел).
* **Прямая, параллельная плоскости.** Если след α в грани проходит через A ∈ OP и B ∈ OQ
  (OP, OQ — рёбра грани) и `OA : OP = OB : OQ`, то △OAB ~ △OPQ (общий угол и пропорциональные
  стороны), значит AB ∥ PQ. Если ребро e ∥ PQ (базовый факт фигуры или цепочка таких фактов),
  то e ∥ AB ⊂ α ⇒ e ∥ α. Плоскость грани G ⊃ e, пересекающая α, пересекает её по прямой,
  параллельной e; через известную точку α в (G) проводим эту прямую.
* **Внутреннее проектирование.** Призма: проекция параллельно боковому ребру на плоскость
  основания; MM′ ∥ NN′ ⇒ MN и M′N′ лежат в одной плоскости и (если не параллельны)
  пересекаются в точке X ∈ α ∩ (основание). Пирамида: центральная проекция из вершины S;
  MN и M′N′ лежат в плоскости (SMN).
* **Координатный метод.** f(X) = ax + by + cz + d; для ребра PQ c разными знаками
  `t = f(P)/(f(P) − f(Q))`.

Каждое утверждение шага (принадлежность плоскостям, пересечение, параллельность)
повторно проверяется численно функцией `verifyConstruction`.
